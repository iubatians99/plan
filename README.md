# Task Tracker (Android app)
1. Create a GitHub repo, upload all these files (keep .github folder), push.
2. Actions tab > "Build APK" > download artifact `task-tracker-apk`, unzip, install app-debug.apk.
3. Open app > tap 🔔 Alerts > Allow. On Android 12+, also allow "Alarms & reminders" for the app, and set battery to "Unrestricted".
4. First photo: paste your free Gemini key when asked (get it at aistudio.google.com/apikey).
Alerts are scheduled on the phone itself, so they fire with the app closed. No server needed.
